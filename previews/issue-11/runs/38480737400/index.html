真实验收门禁：blocked

Copilot Requests 403：必须配置获授权的模型端点，再收集脱敏 E2E 证据。Mock、VSIX 构建和设计截图不能解除门禁。

异常与重试规则

模型请求不自动重放；失败后由用户手动重试。进程重连不补发旧 prompt。恢复原 sessionId 失败时保留错误，不静默新建。权限未决时断线按拒绝处理。

评审入口

里程碑 → 模块边界 → 逐操作契约 → 原型说明

MS-01 · 最小真实 ACP 闭环提案

先验证 v0.4.0：同一 session 两轮真实模型文本、只读工具批准与拒绝、进程重启后恢复原 sessionId。正式 v0.5.0 侧栏交付以前置真实门禁为准。

模块边界

Extension Host 持有项目身份、站点配置、SecretStorage 与 ACP 子进程；Webview 只接收脱敏状态、消息与一次性审批选项。站点编辑从受控 Host 界面进入。

内部协议映射

本产品不需要 HTTP API。原型使用可查看的本地操作映射；具体版本字段与完整 IPC Schema 仍须按锁定 DSH 包实测核对，不能将该演示映射当作正式协议证据。

原型与文档发布

本轮 delivery.prototype_html，发布后由可信流水线回填 Pages 链接与截图。

Wiki Home → 文档目录 → 里程碑 → 模块 → 任务 → IPC → 原型的真实链接，由发布器生成后逐页验收；当前不伪造 Wiki / Pages URL。

只含虚构示例数据；状态保存在当前页面内存，刷新即重置。不保存真实会话，不连接业务后端。
